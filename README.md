# 绿脉晚安生成器

一个为中国农业大学绿脉环保协会制作的晚安文案生成工具。打开网页即可使用，无需注册或登录。

## 功能

- 自定义“第一天”的日期，自动计算当天是第几天晚安
- 按北京时间自动生成日期和星期
- 自动计算农历日期、生肖及年、月、日天干地支
- 实时获取北京海淀和山东烟台的次日天气预报
- 支持自定义文案、环享栏目和编辑人
- 一键生成并复制完整晚安文案
- 自动保存本机上次填写的内容
- 支持电脑、平板和手机浏览器

## 使用方法

1. 打开网站。
2. 设置“第一天日期”。
3. 填写文案、环享栏目和编辑人。
4. 点击“一键生成”。
5. 检查生成结果后，点击“复制全部文案”。

## 天气数据

天气数据来自 [Open-Meteo](https://open-meteo.com/)。每次点击“一键生成”时，网页会联网获取以北京时间计算的次日预报，包括天气状况、最高与最低温度、风力、空气质量以及日出、日落时间。

不同天气平台采用的气象站、更新时间和预报模型可能不同，因此预报结果可能存在差异。使用天气功能时需要保持网络连接。

## 本地运行

下载项目中的 `index.html`，使用浏览器打开即可。该项目为纯 HTML、CSS 和 JavaScript 页面，不需要安装其他依赖，也不需要配置服务器。

## GitHub Pages 部署

1. 确认仓库根目录中存在 `index.html`。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. Branch 选择 `main`，文件夹选择 `/ (root)`。
5. 点击 **Save**，等待 GitHub 完成部署。

部署完成后，网站地址通常为：

```text
https://你的GitHub用户名.github.io/greenpulse-goodnight-generator/
```

## 隐私说明

用户填写的第一天日期、文案、环享栏目和编辑人只保存在当前浏览器的本地存储中，项目本身不会建立用户账户或上传这些内容。
